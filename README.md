# 🔢 Counter App

A simple and interactive Counter App built using **HTML, CSS, and JavaScript**. This project helps beginners understand JavaScript event handling, DOM manipulation, and updating UI elements dynamically.

## ✨ Features

- ➕ **Increment:** Increase the counter value.
- ➖ **Decrement:** Decrease the counter value.
- 🔄 **Reset:** Reset the counter to zero.
- ⚡ **Real-Time Updates:** Instantly display the updated counter value.
- 📱 **Responsive Design:** Works across different screen sizes.
- 🎨 **Clean UI:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** — Structure of the application.
- **CSS3** — Styling and layout.
- **JavaScript** — Counter logic and DOM manipulation.

## 🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd counter-app
   ```

3. Open `index.html` in your browser.

4. Click the increment, decrement, and reset buttons to use the app.
